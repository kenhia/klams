# sprints/review

The kprojects harness reserves this directory for formal reviews.

**klams' reviews live in [`docs/reviews/`](../../docs/reviews/)** — they
predate the harness (the 2026-07-25 deep review and the 2026-07-28
retrospective) and are cited by eight sprint records, so moving them
would break the record they are part of.

New reviews go in `docs/reviews/` too. This file exists so the next
agent finds the reviews instead of starting a second pile here.
